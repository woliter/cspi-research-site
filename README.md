# CSPI Research

Public weekly snapshot of the **China Stablecoin Penetration Index** —
a research project on RMB cross-border pressure derived from stablecoin
flows, anchor-network activity, and standard macro / regulatory signals.

This repository holds only the **academic-version static site** built
each week by the upstream private system. It contains no code, no raw
data, and no private addresses — only HTML / PNG / JSON snapshots with
quintile-binned readings, 7-day lag, and ±5% additive noise per the
methodology archive §12.6 (academic publication track).

The full methodology is described at `/methodology.html` once the site
is deployed.

— CSPI Research Project, 2026
