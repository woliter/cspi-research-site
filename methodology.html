方法学概要

CSPI 的两个核心目标是中国内地居民与机构稳定币渗透程度与中国内地居民与机构跨境稳定币资金流向，采用基于行为与网络证据的概率推断研究路线。 链上研究层以实验评分开展研究，是否已有评分及评分日期见首页；独立验证、概率校准和总体外推分别报告进展。宏观环境子指数提供背景，两个目标的正式估计值尚未发布。

核心总体明确为中国内地居民与机构，不要求每个地址的归属都达到 100% 确定。行为与网络特征用于推断，独立地域或居住地参照用于检验推断误差。 交易所的中国关联背景、机构地址标签及全球客户活动均不能直接转换为内地居民归属。 “中国相关实体在全球稳定币样本中的活动份额”与“内地居民与机构的稳定币使用渗透率”是不同的估计对象，后者还缺少合适的经济活动分母。 跨境方向可以使用经过独立验证与校准的两端归属概率估计，同时报告依赖假设与不确定性，处理内部划转与跨链重复；地址间或链间转移本身不能证明内地与境外之间的资金流动。

从行为评分到概率估计

活动时间、交易网络及通道关联等线索共同支持行为推断；应检验机器人、托管钱包、跨时区活动等替代解释。多个来自同一来源的标签或相互派生的特征不能当作独立验证。

  1. 行为模型：展示已有实验评分及评分日期，评价样本覆盖和不同模型设定下的稳定性。评分只表示关联强弱。
  2. 独立验证：训练、调参与最终评估分开，按实体、证据来源和时间划分；利用较可信的参照检验误判与漏判，报告区间、无评分覆盖和参照标签误差。已有内部诊断不等于居民口径的独立验证通过。
  3. 概率校准：检查预测概率与独立参照中的实际比例是否相符，并报告可靠性与校准误差。未经校准的 0.7 分不能直接解释为 70% 的归属概率。
  4. 总体外推：校准之后还需明确链、币种、期间、覆盖与分母，处理内部及跨链重复，并将标签、模型和采集不确定性传递到汇总结果。

独立参照不要求覆盖全部地址，也不被假定为无误。参照误差与选择偏差需作敏感性分析；在缺少有效参照时，公开行为关联评分及其假设，暂不把评分或其加权和称为已校准的居民概率或全国规模。

2026-10-28 展示口径澄清：四阶段状态分别报告。当前没有完整的自动验收器；判定阈值、标签数量或软件测试通过均不能单独解锁概率与总体估计。本次澄清不改变既有评分算法、宏观读数或学术发布规约。

四类信息并行报告

评阅意见 [S1] 明确要求：CSPI 在指数构建中区分四类信息，分项指数与综合指数并行报告。 计算定义当前登记 36 个分项（包含内部研究项），分为五类信息组。登记不等于已取得有效数据；实际覆盖见首页：

  • 一、全球供给（global_stablecoin_liquidity）：美元稳定币的源头产能、 多发行人供给扩张与铸赎净流。 含 GlobalStablecoinSupply（USDT/USDC/DAI/USDS/USDe/FDUSD/PYUSD/USD1/TUSD/RLUSD 十发行人合计市值，CoinGecko 主源 + DeFiLlama 兜底）、TetherIssuanceFlows （配置国库钱包集合与外部转账的观测代理，不代表铸赎或全球净新增发行）、LicensedStablecoinFlow （HKMA 持牌发行人净发行）。
  • 二、离岸价格（offshore_price_pressure）：人民币离岸/在岸价差、 美元离岸借贷成本与境内场外报价。 含 RMBPressure（USDCNH 现货 + 1Y 远期 + USDCNY 中间价 + CFETS）、 OffshoreLiquidity（CNH HIBOR）、CipBasisFull / CipBasisProxy （三国 + 中国 CIP basis）、CnhDepositsHk（香港 CNH 存款余额）。
  • 三、中国关联链上活动（cn_linked_onchain_activity）： 启发式中国关联地址样本活动与网络应用代理；尚未识别总体份额。 含 CnShareCombined（网络与应用代理，口径待重构，不参与实验层汇总）及若干 anchor 驱动事件证据支柱（具体形式与命名属于待申请专利范围，公开站点仅以聚合 指标「中国关联地址样本活动（实验）」展示，不暴露各支柱细节、不暴露 地址级数据、不针对任何具体主体）。
  • 四、跨境流向研究（crossborder_flow_evidence）：样本转账方向代理与传统 跨境通道背景，尚不构成已识别的稳定币跨境净流量。 含 SouthboundFlow（港股通南向）、SafeForexBalance（外管局结售汇）、 ForexSettlement、BopFlows（季度经常账户）、HotMoneyResidual（月频剩余法）、 BopErrorsOmissions（独立的季度净误差与遗漏）、CnUsKycBridgeOutflow / CnUsKycBridgeInflow （样本与标记交易所地址之间的方向代理；机构或客户所在地尚未核实，不能直接解释为跨境资本流动）。
  • 五、对照变量集（controls）：GlobalUSDStress_simple、 USYieldCurve、OilStress、GoldPremium、PbcLiquidityOps、AnnualBenchmark。 用于残差化分离共同冲击，不进入 宏观环境子指数 headline。

支柱治理规则（v2.5）

以下 headline 指宏观环境子指数及实验层内部合成读数，独立验证、概率校准与总体外推另行评价。治理层分别管理监测分项与合成资格。 cspi_index 表保留全部 36 个 pillar 的标准化监测值 用于诊断 / 回测 / 研究；CSPI-v0 headline 经过以下门控才纳入：

  1. 已废弃支柱（如 StockConnectFlow，因 Wind+HKEX 上游 2024-08 停发）→ 不进 headline；
  2. metadata 缺失 → 视作 event_evidence，不进 headline；
  3. role == control → 仅作残差化对照，不进 headline；
  4. role == event_evidence（如所有 Phase 2 anchor 支柱）→ 仅作事件证据， 不进 headline；
  5. n_obs < 30 硬门槛 → 样本不足，降为 event_evidence；
  6. n_obs < min_headline_obs（默认 180）或 n_signals ≤ 1 或 role == headline_supporting → 以基础权重 × 0.35 的降权进入 headline；
  7. 超过该分项频率允许的最大陈旧天数 → 权重归零；其余按基础权重纳入。

该规则在每个历史日期都重新评估（ex-ante 分类，2026-05-20 审查 P0#3 修复）：不会用今天的 n_obs 反推过去的状态。网站与内部诊断调用同一合成函数。

残差化诊断（CSPI-v1 原型）

对照变量集（GlobalUSDStress_simple / USYieldCurve / OilStress / GoldPremium / PbcLiquidityOps，5 项非年频 control）用 OLS 投影出共同冲击成分， 对每个 headline pillar 残差化后再按 headline 权重归一，得到 residualized_headline_z 诊断量。残差标准差使用 OLS (n−p) 自由度修正（2026-05-20 审查 P0#2 修复）， 分母再叠加预测区间 SE 以反映参数估计不确定性。 该层只写诊断文件 output/diagnostics/，不写入数据库， 也不替代公开 CSPI-v0 headline；属于 CSPI-v1 研究增强原型。

标准化与合成

首先按序列声明进行变换。香港离岸人民币存款总额、全球美元稳定币合计市值使用相邻观测对数增长率； 价格、利率与价差目前保留水平。增长率口径仍需检查季节性，水平序列仍需检验平稳性，不能用标准化替代这些检验。

然后在扩展窗口内计算标准化读数，均值、标准差与截尾边界只使用当前及更早观测。 该约束针对同一数据版本；上游修订、口径变化和固定参考权重仍可能改变重算历史。 分项内部按当天或之前的最近有效成分进行对齐，并在超过成分允许的陈旧期限后剔除；按声明方向等权聚合成分。

跨分项合成同样采用向前携带最近观测的方式，并按各分项发布频率设定最大陈旧期限。 基础权重先按信息组划分，再按登记的参考逆波动权重分配到组内；样本量和信号数决定质量折扣。 缺项、过期或降权后，信息组的实际份额可能不相等；该方法不等同于使用完整协方差矩阵的风险平价。 网站和内部诊断使用同一合成函数，并只读取所选指数计算方法。

发布日期与回测边界

当前以观测日期进行滞后筛选；月季频官方数据的首次发布日期与后续修订版本尚未完整入库。后视对齐不等于按当时真实可获得的数据回测，不能据此声称无发布滞后偏差。

事件验证

已实现（cspi validate-robustness）： leave-one-pillar-out 逐支柱剔除、±25% 权重扰动 Monte-Carlo（含符号翻转率）、 以及对 headline 时间序列的 Künsch 移动块 bootstrap 置信区间。 尚未实现：事件窗口 event study 与 placebo 检验—— USDC 脱锚、Tornado Cash 制裁、9.24 禁令、LUNA/UST、GENIUS Act 等事件 目前仅用于定性解读，尚无系统化的事件响应统计检验，属研究 backlog。

可复核边界（Reproducibility Boundary）

本平台采用分层披露策略，明确学术研究的可复核范围与不公开内容的方法学理由：

公开披露：

  • 变量类别：四类信息分组与每个分项的口径定义；
  • 数据来源类型：宏观（Wind/FRED/IMF/BIS/CEIC）、链上 （公开节点 + Bitquery 等可订阅源）、官方与监管公开数据；
  • 合成方法：平稳性变换（按序列声明 level / dlog / 同比，见下）→ z-score 扩窗标准化（expanding，仅用 t 时点及之前数据， 同一数据版本下不引入未来观测）→ 信息组基础权重（组内按参考逆波动）→ 质量与新鲜度门控； 另有动态因子提取（诊断用）；
  • 待完成验证：独立标签校准、事件窗口与 placebo 检验；当前不能据此宣称完整识别已成立。
  • 残差化诊断：对已登记的五项非年频对照变量作 OLS 投影；该诊断不替代公开主指数，也不自动证明中国特定识别。

不公开（作为知识产权与研究有效性保护内容）：

  • 具体地址聚类库与种子地址列表；
  • 启发式识别的阈值参数与传播权重；
  • 内部版精确 z 值与原始指标。

不公开的学术理由：识别参数一旦公开会被对抗性绕过，导致研究有效性退化； 公开的变量类别、来源类型与合成方法便于口径核对；完整数值复现仍需相应原始数据、版本档案和受控研究材料。

三轨发布（§12.6）

  1. 内部版：精确 z + 原始指标，仅本地。
  2. 合作研究版：脱标签、加噪、按需共享。
  3. 学术发布版（本网站）：至少滞后 7 天，默认使用标准差 5% 的高斯乘法噪声（并非 ±5% 的硬范围），再作分位离散化。图表仅从公开分位绘制。
