方法学概要

CSPI（China Stablecoin Penetration Index，稳定币跨境渗透综合识别指数）测度的不是 抽象意义上的"跨境渗透"，而是 由稳定币发行、离岸价差、锚点行为、跨境桥接与境内关联活动共同表征、 与传统美元流动性外溢可区分的中国关联稳定币活动强度。

四类信息并行报告

评阅意见 [S1] 明确要求：CSPI 在指数构建中区分四类信息，分项指数与综合指数并行报告。 当前注册表共 32 个活动支柱，分为五类信息组：

  • 一、全球供给（global_stablecoin_liquidity）：美元稳定币的源头产能、 多发行人供给扩张与铸赎净流。 含 GlobalStablecoinSupply（USDT/USDC/DAI/USDS/USDe/FDUSD/PYUSD/USD1/TUSD/RLUSD 十发行人合计市值，CoinGecko 主源 + DeFiLlama 兜底）、TetherIssuanceFlows （Tether Treasury 铸赎净流的高频领先信号）、LicensedStablecoinFlow （HKMA 持牌发行人净发行）。
  • 二、离岸价格（offshore_price_pressure）：人民币离岸/在岸价差、 美元离岸借贷成本与境内场外报价。 含 RMBPressure（USDCNH 现货 + 1Y 远期 + USDCNY 中间价 + CFETS）、 OffshoreLiquidity（CNH HIBOR）、CipBasisFull / CipBasisProxy （三国 + 中国 CIP basis）、CnhDepositsHk（香港 CNH 存款余额）。
  • 三、中国关联链上活动（cn_linked_onchain_activity）： 基于公开地址聚类启发式的中国关联活跃度与全球链上份额。 含 CnShareCombined（OpenCelliD + Cloudflare + 七麦三源融合）及若干 anchor 驱动事件证据支柱（具体形式与命名属于待申请专利范围，公开站点仅以聚合 指标「中国相关链上活动合成」展示，不暴露各支柱细节、不暴露 地址级数据、不针对任何具体主体）。
  • 四、跨境流向（crossborder_flow_evidence）：稳定币跨境桥接与传统 跨境通道的资金流量对照。 含 SouthboundFlow（港股通南向）、SafeForexBalance（外管局结售汇）、 ForexSettlement、BopFlows（季度 BoP）、HotMoneyResidual（剩余法热钱 + 净误差与遗漏混合）、CnUsKycBridgeOutflow / CnUsKycBridgeInflow （中美 KYC 桥事件，机构层 settlement 观察，非 retail capital flight 解读）。
  • 五、对照变量集（controls）：GlobalUSDStress_simple、 USYieldCurve、OilStress、GoldPremium、PbcLiquidityOps、AnnualBenchmark。 用于残差化分离共同冲击，不进入 CSPI 主体 headline。

支柱治理规则（v1.7）

v1.7 把"所有 pillar 的等权监测表"与"可公开解释的 headline 指数"明确分开。 cspi_index 表保留全部 32 个 pillar 的标准化监测值用于诊断 / 回测 / 研究；CSPI-v0 headline 经过以下 7 步门控才纳入：

  1. 已废弃支柱（如 StockConnectFlow，因 Wind+HKEX 上游 2024-08 停发）→ 不进 headline；
  2. metadata 缺失 → 视作 event_evidence，不进 headline；
  3. role == control → 仅作残差化对照，不进 headline；
  4. role == event_evidence（如所有 Phase 2 anchor 支柱）→ 仅作事件证据， 不进 headline；
  5. n_obs < 30 硬门槛 → 样本不足，降为 event_evidence；
  6. n_obs < min_headline_obs（默认 180）或 n_signals ≤ 1 或 role == headline_supporting → 以基础权重 × 0.35 的降权进入 headline；
  7. 其余 → 以完整基础权重进入 headline。

该规则在每个历史日期都重新评估（ex-ante 分类，2026-05-20 审查 P0#3 修复）：不会用今天的 n_obs 反推过去的状态。

残差化诊断（CSPI-v1 原型）

对照变量集（GlobalUSDStress_simple / USYieldCurve / OilStress / GoldPremium / PbcLiquidityOps，5 项非年频 control）用 OLS 投影出共同冲击成分， 对每个 headline pillar 残差化后再按 headline 权重归一，得到 residualized_headline_z 诊断量。残差标准差使用 OLS (n−p) 自由度修正（2026-05-20 审查 P0#2 修复）， 分母再叠加预测区间 SE 以反映参数估计不确定性。 该层只写诊断文件 output/diagnostics/，不写入数据库， 也不替代公开 CSPI-v0 headline；属于 CSPI-v1 研究增强原型。

标准化与合成

当前公开运行版为 CSPI-v0：每个 pillar 内部对其底层信号做 expanding-window z-score 标准化 （2026-05-20 审查 P0#1 修复：每个观察 t 的 mu / sigma / 1-99 percentile 仅用 [t_0, t] 区间，不包含未来信息；这是 IMF FSI、Hatzius FCI、 ECB CISS 等公开金融压力指数的标准做法，可保证历史 z 不随今日数据变化）。 pillar 内多源信号以 equal_weighted_v0 聚合为 composite_z。 跨 pillar headline 序列再做 forward-fill 跨频率拼接： 日频、月频、季频支柱的最新 z 沿日历前推到下一个观察日，避免低频支柱 在月末当日"突然入分母"造成 headline 尖峰。

事件验证

在 USDC 脱锚（2023-03）、Tornado Cash 制裁（2022-08）、 中国 9.24 加密禁令（2021-09）、LUNA/UST 崩盘（2022-05）、 GENIUS Act 通过（2025）等关键事件窗口对 CSPI 进行可解释响应检验， 并对 OTC 溢价异常、CNH-CNY 价差波动、跨境桥接流量突变做交叉验证。 事件 study、placebo、leave-one-pillar-out 等系统性 robustness 实验属于 论文阶段工作，参见研究 backlog。

可复核边界（Reproducibility Boundary）

本平台采用分层披露策略，明确学术研究的可复核范围与不公开内容的方法学理由：

公开披露：

  • 变量类别：四类信息分组与每个分项的口径定义；
  • 数据来源类型：宏观（Wind/FRED/IMF/BIS/CEIC）、链上 （公开节点 + Bitquery 等可订阅源）、官方与监管公开数据；
  • 合成方法：z-score 滚动标准化（365d）、动态因子提取、 等权重 / 主成分 / 滚动窗口三种权重比较；
  • 验证标准：脱锚事件、监管事件、OTC 溢价异常、 CNH-CNY 价差波动、跨境桥接流量突变等事件窗口的可解释响应；
  • 残差化步骤：先以 VIX、DXY、加密市场总市值、 TED 利差等做投影，对残差再做因子提取，分离渗透特定信息。

不公开（作为知识产权与研究有效性保护内容）：

  • 具体地址聚类库与种子地址列表；
  • 启发式识别的阈值参数与传播权重；
  • 内部版精确 z 值与原始指标。

不公开的学术理由：识别参数一旦公开会被对抗性绕过，导致研究有效性退化； 公开变量类别、来源类型与合成方法已足以支持外部检验与方法学复现。

三轨发布（§12.6）

  1. 内部版：精确 z + 原始指标，仅本地。
  2. 合作研究版：脱标签、加噪、按需共享。
  3. 学术发布版（本网站）：滞后 7 天 + ±5% 噪声 + 5 分位离散化。

平台功能边界

本平台输出仅用于学术研究与方法学展示，不构成对任何具体主体的监测、监管建议或投资建议。所有链上识别均以公开地址聚类与启发式为基础，以聚合统计指标为单位，不公开任何单一主体级别的判定。
